# API reference

One page per source family (`src/<family>/`). Each page lists:

- the docstrings of the exported names of the family;
- for the high-level API, the non-exported functions (`OxiBLAS.lu`,
  `OxiBLAS.ldiv`…), called with the `OxiBLAS.` prefix;
- the exported names that do not have a docstring yet: their convention is
  described in the guides.

These pages are generated by `docs/make.jl` from the docstrings and from the
source file of each method.
