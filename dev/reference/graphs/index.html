Graphes et ordonnancements

Sources : src/graphs/.

OxiBLAS.bipartite_coloring — Function

Two-color the undirected off-diagonal pattern (diagonal entries ignored).

source
OxiBLAS.bipartite_graph_matching — Function

Maximum-cardinality matching of a square undirected bipartite graph. The off-diagonal pattern is symmetrized; diagonal and numerical zeros ignored. Returns nothing for a non-bipartite graph. This differs from bipartite_matching, which treats a rectangular matrix as a row/column bipartite incidence pattern.

source
OxiBLAS.column_minimum_degree — Function

Exact column minimum-degree on implicit row-clique elements. Ports the ordering semantics of Rust colamd/colamdaggressive, whose upstream documentation explicitly disclaims real COLAMD. No numerical A'*A or initial column-intersection graph is materialized. Overlapping elements are unioned to compute exact degrees; worst-case work/fill is still superlinear. densethreshold in [0,1] ignores rows denser than that fraction of columns. absorb removes elements contained in the new fill element; no supercolumn merging or SuiteSparse aggressive-absorption equivalence is implied.

source
OxiBLAS.degree_sequence — Function

Off-diagonal undirected degrees; diagonal entries and numerical zeros ignored.

source
OxiBLAS.graph_bandwidth_profile — Function

Graph convention used by upstream graph::bandwidthprofile: bandwidth is max(abs(i-j)), profile is the sum of each row's max-column minus min-column, including the diagonal location in the envelope, and averagebandwidth is profile/n. Distinct from bandwidth_profile's full matrix width/lower envelope.

source
OxiBLAS.multilevel_nested_dissection — Function

Nested dissection using multilevel bisection and a greedy vertex cover of cross edges. Every reported separator removes all left/right cross edges. Leaf minimum-degree ordering is exact; separators need not be minimum size. return_tree=true exposes the separator tree for structural inspection.

source
OxiBLAS.multilevel_partition — Function

Native recursive k-way multilevel partitioning. Heavy-edge contraction, BFS initial bisection, greedy moves/pair swaps or locked best-prefix FM (refinement=:fm) on uncoarsening. Default :greedy preserves the prior policy. No METIS-equivalent quality or balance guarantee is claimed: balanced reports the achieved global load criterion. The algorithms are currently sequential.

source
OxiBLAS.multiple_minimum_degree — Function

Multiple minimum degree (Liu): every independent variable of minimum degree is eliminated in one round before the degrees are updated, on the quotient graph with supervariables of minimum_degree_ordering.

source
OxiBLAS.ordering_metrics — Function

Exact symbolic fill count and bandwidth/profile for an explicit permutation. This can be expensive: symbolic fill is computed, not cheaply predicted.

source
OxiBLAS.pseudo_peripheral_vertex — Function

Pseudo-peripheral vertex in the starting connected component. Empty graphs return 0; the iteration alternates minimum-degree vertices in the farthest BFS level until its depth stops increasing. No global-diameter guarantee.

source
OxiBLAS.refine_partition — Function

Refine a supplied two-way labeling using locked best-prefix FM passes or existing greedy moves/pair swaps. Labels are copied, never modified in place. The retained result improves balance violation first, then cut, in working precision; balanced reports the requested left fraction, not an optimum. Temporary exploration can exceed the requested weight tolerance by one vertex.

source
OxiBLAS.sparse_ordering — Function

Select a native ordering; permutation[newindex] is the old index. :amd is approximate minimum degree on A+Aᵀ (Cholesky, LDLᵀ); `:amdataon AᵀA without dense rows (LU) and:amdqron AᵀA (QR), the COLAMD substitutes of CSparse.:minimumdegree` is the exact (slower) variant. Rectangular matrices support :natural, :columnminimumdegree, :amdata and :amdqr.

source
OxiBLAS.weighted_bipartite_matching — Function

Weighted row/column bipartite matching on the nonzero pattern of A. objective=:cardinality first maximizes cardinality, then total weight; :weight permits unmatched vertices to maximize weight (zero-cost ties may increase cardinality). weight=:auto uses signed real values or complex abs; :value, :abs and :logabs are also supported. Missing/zero entries are not edges. Uses scaled Float64 costs, sparse residual arcs and Dijkstra potentials. Optimality is in working precision, not an exact-arithmetic certificate.

source
OxiBLAS.weighted_graph_matching — Function

Weighted matching of a square bipartite adjacency graph. Returns nothing for a non-bipartite pattern. Undirected weights use max of the two transformed directions, explicitly handling one-triangle/asymmetric storage.

source
