Tenseurs

Sources : src/tensors/.

OxiBLAS.EinsumWorkspace — Type

Reusable tensor-intermediate buffers, protected for concurrent callers. An execution leases separate buffers for simultaneously live intermediates. Returned arrays never expose these buffers; einsum! also reuses its result scratch. Packing/index metadata may still allocate. Retained capacity is not bounded by a plan's live-payload memory_limit. Use empty! between campaigns.

source
OxiBLAS.SlicedEinsumPlan — Type

A contraction plan executed as serial tiles; arrays remain ordinary Julia arrays. scratch_limit bounds the modeled live tile/intermediate payload, excluding the caller-owned full output, inputs, alias snapshots, pool retention and packing. Tile kernels may use native threading; reductions across tiles are ordered.

source
OxiBLAS.SparseTensor — Type
SparseTensor{T,N} <: SparseArrays.AbstractSparseArray{T,Int,N}

Coordinate sparse tensor of any order: stored entries are kept as sorted, unique column-major linear indices with their values. Explicit stored zeros are preserved; reshape only changes the dimensions (the linear indices are the same). Construct from coordinates (duplicates combined with combine), from a dense array (droptol), or from SparseMatrixCSC, SparseVector and the OxiBLAS sparse formats without any dense intermediate.

source
OxiBLAS.batched_matmul — Function

N-D batched matrix multiplication: dimensions 1/2 are matrix dimensions; remaining dimensions broadcast independently (including singleton batch axes).

source
OxiBLAS.cp_als — Function

CANDECOMP/PARAFAC by alternating least squares with native MTTKRP/GEMM and LU solves. Real and complex arrays are supported. initial can provide factors; otherwise deterministic, nonrandom factors are used. Convergence and stagnation are reported separately from the attained approximation error.

source
OxiBLAS.einsum — Function

Einstein summation on Julia arrays. Complex values are multiplied without implicit conjugation. Scalar expressions return a zero-dimensional Array. Operands may be sparse (SparseTensor, SparseMatrixCSC, SparseVector, OxiBLAS sparse formats, and their transposes/adjoints): they are contracted without densification. output=:auto returns a SparseTensor when every operand is sparse and a dense Array otherwise; :dense / :sparse force the kind.

source
OxiBLAS.einsum_layout_report — Function

Explain a plan's arithmetic and physical-layout model without reading data. Traffic is a heuristic scalar-entry score, not measured bytes/time or a guarantee that a reshape copies. Reusing a plan on other strides keeps correctness but may change the merits of its path. No measured-speed optimality is claimed.

source
OxiBLAS.hosvd — Function

Truncated higher-order SVD, using the native one-sided Jacobi SVD.

source
OxiBLAS.mode_product — Function

Multiply mode mode by U (new dimension × old dimension).

source
OxiBLAS.plan_einsum — Function

Build a reusable shape-checked contraction plan. Supports ellipsis broadcasting, repeated labels (diagonals/traces), scalar outputs, reductions, and any operand count. Greedy planning minimizes local pair work, then intermediate size. :beam keeps bounded-width candidate paths; :optimal exhaustively minimizes modeled pair work with peak payload as a tie-breaker. Both enforce search_limit and throw on exhaustion; optimality concerns this cost model, not measured runtime. :none bypasses pair planning and evaluates the all-operand contraction directly. memory_limit bounds live intermediate tensor payload in bytes, including the result and a conservative output permutation copy, excluding caller inputs, planner metadata, per-worker index vectors, and BLAS packing workspaces. It is not a process RSS cap. If no pair fits, contract all operands directly with no pair intermediates; this can be substantially slower. The output must fit.

source
OxiBLAS.plan_einsum_sliced — Function

Plan explicit named-label tiles, e.g. chunks=(i=16,k=32). A sliced reduction accumulates partial sums; slicing output labels writes disjoint output tiles. ASCII labels, repeated labels and unsliced broadcast ellipses are supported. There is no dense Tensor container and no process/RSS or out-of-core guarantee.

source
OxiBLAS.tensor_train — Function

Sequential TT-SVD. maxrank caps each bond; rtol bounds the discarded Frobenius norm per split by rtol*norm(A)/sqrt(N-1).

source
