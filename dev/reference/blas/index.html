BLAS 1, 2, 3 and GEMM

Sources: src/blas/.

OxiBLAS.GemmConfig — Type

Cache blocking. Defaults adapt upstream MC=576, KC=448/896, NC≈2048.

source
OxiBLAS.GemmWorkspace — Type
GemmWorkspace(T, m, n, k; config=GemmConfig(T), workers=Threads.nthreads())

Reusable panels padded toward 128-byte alignment, one pair per worker. SIMD loads require only natural real-scalar alignment, never user-array alignment. A workspace serializes concurrent calls that share it; separate workspaces run independently. Task migration never changes buffer ownership. Reconstruct if dimensions/config grow.

source
OxiBLAS.GenericWorkspace — Type

Reusable tile accumulation buffers for extended GEMM. A shared context is serialized; different worker buffers belong to different tasks. Float16 uses Float32 accumulators. Arbitrary floating types never enter native SIMD pointer kernels.

source
OxiBLAS.RotmParams — Type

Modified Givens parameters in BLAS order (flag,h11,h21,h12,h22). Flags -2/-1/0/1 select identity/full/unit-diagonal/implicit-off-diagonal forms. Ignored fields need not be initialized. Compatible AbstractFloat scalars use their own arithmetic; native real floats retain SIMD.

OxiBLAS.dsdot — Function

Float32-input inner product, products and accumulation in Float64.

OxiBLAS.gemm! — Function
gemm!(C, A, B, α=1, β=0; transA=:N, transB=:N, algorithm=:auto,
      kernel=:auto, threaded=true, workspace=nothing, config=GemmConfig(eltype(C)))

Compute C ← α op(A) op(B) + β C in native Julia. Equal Float32/64 or ComplexF32/64 element types; 1-based matrices and views. Overlapping inputs are snapshotted before writing C. β=0 never reads old C; α=0 or K=0 never reads A/B. Algorithms: reference, blocked, packed, register, simd, auto. Explicit unavailable ISA requests throw before changing C.

source
OxiBLAS.gemm_batched! — Function

Independent batched GEMM with cross-batch alias snapshots and task-owned panels. threaded=false disables the outer schedule; no nested GEMM tasks are created. A homogeneous batch may reuse one GemmWorkspace sized for its largest members.

source
OxiBLAS.gemm_cache_oblivious! — Function

Cache-oblivious largest-dimension recursion with native SIMD leaf kernels. Parallel output regions have task-owned packing panels and no nested tasks.

source
OxiBLAS.gemm_strassen! — Function

Native Strassen seven-product recursion, including odd-dimension fringes. This trades additional workspace and rounding error for fewer products; select it explicitly after checking the application's accuracy and performance needs.

source
OxiBLAS.gemm_strided_batched! — Function

GEMM on 3-D Julia arrays; dimension three is the independent batch index.

source
OxiBLAS.gemm_winograd! — Function

Native Strassen–Winograd addition schedule with seven recursive products.

source
OxiBLAS.gemmt! — Function
gemmt!(C,A,B,α=1,β=0;uplo=:U,transA=:N,transB=:N,blocksize=128,...)

C[triangle] ← α op(A) op(B) + β C[triangle], preserving the other triangle. Rectangular inputs, N/T/C, alias snapshots and GEMM options are supported. Only diagonal tiles use temporary output storage, bounded by blocksize².

Euclidean norm with scaled sum of squares; avoids spurious overflow/underflow.

Return (c,s,r), ca+sb=r and cb-conj(s)a=0 (real c).

OxiBLAS.rotm! — Function
rotm!(x,y,p::RotmParams)  # or five-element BLAS parameter vector

Apply the modified Givens matrix to pairs (x[i],y[i]) in native Julia. Negative/nonunit strides are supported. Nonidentity rotations require disjoint outputs with distinct entries. Identity never reads or writes vector entries. Parameter vectors are read before any mutation, including when they alias x/y.

source
OxiBLAS.rotmg! — Function

rotmg!(state,y1) updates [d1,d2,x1] after successful generation and returns parameters.

source
OxiBLAS.sdsdot — Function

sdsdot(alpha::Float32,x,y) accumulates alpha and Float32 products in Float64, then rounds once to Float32.

source
OxiBLAS.triangular_workspace — Function

Reusable native TRMM/TRSM packing context for an m-by-n output. Construct once for a fixed side/configuration; pass as workspace with the same config. The scalar/generic fallback requires no packing context.

source
OxiBLAS.trmm! — Function

In-place triangular multiplication; recursive blocks use native GEMM. blocksize sets the scalar leaf size. GEMM options control off-diagonal updates. Only aliased A requires a full logical snapshot; B is never fully copied.

source
OxiBLAS.trsm! — Function

Triangular solve with recursive native-GEMM updates and reusable panels. A singular nonunit diagonal is reported before any mutation of B.
