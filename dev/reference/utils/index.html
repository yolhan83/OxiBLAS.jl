Utilitaires, matériel et précision

Sources : src/utils/.

OxiBLAS.autotune_gemm — Function

Explicit, opt-in native GEMM calibration. Calling this function runs timings; loading the package never calibrates or benchmarks. Candidate results are checked against the native reference before their measured time is accepted.

source
OxiBLAS.dot_extended — Function

Compensated dot product in a caller-selectable accumulation type. Float16/32 default to Float32/64; other providers preserve their element type. accumulator_type can explicitly select BigFloat, Double64, Float128, etc. Products are rounded by that type; no hidden fixed extended scalar is used.

source
OxiBLAS.gemm_extended! — Function

Compatibility entry point for GEMM with caller-provided floating types. Native Float32/64 retain specialized dispatch; other concrete AbstractFloat and complex floating types use generic Julia arithmetic. No scalar is wrapped or reimplemented by OxiBLAS. Float16 GEMM accumulates in Float32.

source
OxiBLAS.generic_threadsafe — Function

Whether scalar arithmetic has a context safe to use in spawned kernel tasks. Machine floats are enabled. Other providers conservatively execute kernels in one task, preserving the caller's arithmetic context (notably BigFloat precision). Providers may extend this OxiBLAS function explicitly; no Base method is needed.

source
OxiBLAS.kernel_info — Function

Report selected kernel, vector width, and micro-panel dimensions.

source
OxiBLAS.load_gemm_tuning — Function

Load tuning only for the same CPU, Julia version, thread count and type. Returns the config/kernel/shape; it never starts a new calibration.

source
OxiBLAS.save_gemm_tuning — Function

Save an explicitly measured configuration in a simple versioned text file.

source
