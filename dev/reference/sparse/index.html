Sparse matrices

Sources: src/sparse/.

OxiBLAS.AINVPreconditioner — Type

Factored sparse approximate inverse ZDiagonal(1/d)W'. Biconjugation without pivoting; a zero/nonfinite pivot is reported explicitly. Dropping is relative to each updated column and retains its unit diagonal.

source
OxiBLAS.COOMatrix — Type

Canonical coordinate sparse storage. Duplicate coordinates are summed and exact zero entries are removed during construction.

source
OxiBLAS.CSCMatrix — Type

Owned compressed-column sparse matrix with validated 1-based indices.

A SparseArrays.AbstractSparseMatrix, like the other OxiBLAS formats (not an AbstractSparseMatrixCSC: operations on OxiBLAS sparse types end in OxiBLAS kernels, not in inherited SparseArrays ones; see reports/ARCHITECTURECSCAvsB.md). Row indices are unique and sorted within each column, so SparseMatrixCSC(A) always shares the storage; explicit stored zeros are allowed, as in SparseMatrixCSC.

source
OxiBLAS.CSRMatrix — Type

Owned CSR matrix. Indices are 1-based; duplicate columns in a row are rejected. Real, complex and generic (e.g. BigFloat) scalars; explicit zeros are kept.

source
OxiBLAS.amd_ordering — Function
amd_ordering(A; kind=:symmetric)

Approximate minimum degree ordering of A+Aᵀ (kind=:symmetric, for Cholesky and LDLᵀ), of AᵀA (:ata, for QR) or of AᵀA without dense rows (:ata_sparse, for LU). Returns p with p[new] = old.

source
OxiBLAS.amg — Function

Aggregation algebraic multigrid for Hermitian positive-definite sparse A. Piecewise-constant aggregates may be smoothed before Galerkin coarsening. V/W cycles use weighted Jacobi and a native sparse Cholesky coarse solve.

source
OxiBLAS.bicgstab — Function

BiCGStab for real/complex nonsymmetric systems with right preconditioning. Reports true residuals and explicit breakdown/maxiter termination.

source
OxiBLAS.bipartite_matching — Function

Maximum-cardinality row/column matching by layered, iterative Hopcroft–Karp. Returns row/column partner arrays (0 means unmatched), retaining the existing rectangular incidence interpretation. Use bipartitegraphmatching for a square adjacency graph interpreted through an undirected two-coloring.

source
OxiBLAS.block_cg — Function

Coupled block preconditioned CG for multiple Hermitian positive-definite systems. Rank loss in the block Gram system triggers explicit scalar PCG continuation from the current iterates, rather than inverting a singular block.

source
OxiBLAS.block_gmres — Function

Restarted right-preconditioned block GMRES with block Arnoldi and native minimum-norm projected least squares. Rank loss falls back to independent flexible GMRES continuations; the returned fallback flag makes this explicit. maxiter counts block Arnoldi steps.

source
OxiBLAS.cg — Function

Conjugate gradient for Hermitian positive definite matrices; optional positive real Jacobi diagonal. Reports the true residual and a termination reason.

source
OxiBLAS.colamd_ordering — Function
colamd_ordering(A)

Column approximate minimum degree ordering of A (COLAMD, ported from SuiteSparse): a column permutation q (q[new] = old) that keeps the factors of AᵀA, the R of A[:,q] = QR and the L, U of A[p,q] = LU sparse. Stored zeros are ignored.

source
OxiBLAS.fgmres — Function

Flexible right-preconditioned restarted GMRES. A callable preconditioner has signature P(z,r,iteration), so it may change between Arnoldi steps. Stored preconditioned basis vectors make this flexibility mathematically valid.

source
OxiBLAS.gmres — Function

Restarted, left-preconditioned GMRES with two-pass modified Gram–Schmidt. Convergence is checked against the true, unpreconditioned residual every restart. preconditioner may be nothing, a diagonal vector, or an ILUFactor.

source
OxiBLAS.idrs — Function

IDR(s) with an orthonormal local shadow space, oblique Sonneveld-space updates, angle-stabilized omega and optional fixed right preconditioning.

source
OxiBLAS.ilu0 — Function

Zero-fill incomplete LU on the input sparsity pattern. Requires explicit, nonzero pivots; numerical breakdown is reported rather than silently patched.

source
OxiBLAS.lanczos — Function

Fully reorthogonalized Hermitian Lanczos projection and Ritz eigenpairs. Returns explicit residuals and convergence flags. which is :smallest or :largest algebraic. A supplied start vector determines the explored subspace.

source
OxiBLAS.ldl_inertia — Function

Inertia from real/Hermitian pivot blocks in working precision. tol applies to D-block eigenvalues, not to eigenvalues of A or a certified spectral gap.

source
OxiBLAS.minres — Function

Paige–Saunders short-recurrence MINRES for Hermitian systems, including indefinite matrices. The optional fixed preconditioner must be Hermitian positive definite. Every reported convergence uses the true residual.

source
OxiBLAS.multifrontal_cholesky — Function

Supernodal multifrontal Hermitian Cholesky of the uplo triangle of A, P·A·Pᵀ = L·Lᴴ, with a fill-reducing ordering (AMD by default). The dense fronts use this package's POTRF/TRSM/HERK (threaded lets them use threads). supernodal=:auto follows CHOLMOD: an up-looking simplicial factorization when flops/nnz(L) < 40 (chain-like factors), supernodal otherwise; true or false force one of them. maxwidth caps the supernode width; uncapped by default, as in CHOLMOD (a cap of 64 split the 3D separators and ran HERK at rank 64: ×1.35 against CHOLMOD on a 40³ Laplacian instead of ×1.10).

source
OxiBLAS.multifrontal_lu — Function

Row-element multifrontal LU with separate row and column permutations. A[p,q]=L*U. Original row elements and child Schur contributions are assembled once, factored in fully summed panels and forwarded through an assembly tree. Threshold partial row pivoting searches all candidate rows of the front. Independent fronts run concurrently; inner TRSM/GEMM disable nested threading. No dense global Schur matrix or wrapper around blocked sparse LU is used.

source
OxiBLAS.nested_dissection — Function

BFS level-separator nested dissection, with exact local minimum-degree leaves, disconnected-component handling and an explicit recursion depth cap. Use return_tree=true to inspect separators and achieved size balance.

source
OxiBLAS.out_of_core_cholesky — Function

Native tiled disk Hermitian Cholesky, with the same cache/budget contract as outofcore_lu. Only uplo is read. Cache files are local native-endian tiles, checksummed and shape/type checked; they are not portable persistent checkpoints.

source
OxiBLAS.out_of_core_lu — Function

Native tiled disk LU with global panel row pivoting. The byte budget covers numeric panel/tile/packing payload, not CSR input, returned solutions, metadata or process RSS. Tile size shrinks to fit; an insufficient budget is rejected. Call close on the returned owned cache when finished; GC cleanup is best effort.

source
OxiBLAS.pcg — Function

Preconditioned conjugate gradients with an explicit positive-definite preconditioner and true residual checks. Breakdowns are never convergence.

source
OxiBLAS.qmr — Function

Unpreconditioned two-sided QMR, using A and A' products and short bi-Lanczos recurrences. True residuals govern all termination decisions.

source
OxiBLAS.spai — Function

Sparse approximate inverse from independent column least-squares problems. pattern_levels expands the initial column graph support. Each task owns its sparse QR and scratch; assembly happens after all column solves complete.

source
OxiBLAS.sparse_cholesky — Function

Sparse Cholesky in the natural order, A = L·Lᴴ. Fill is stored sparsely, never in a dense matrix. The exact factor goes through the supernodal code of multifrontal_cholesky (natural ordering; the postorder is undone); fill=:zero gives IC(0) and positive droptol threshold IC, by left-looking columns.

source
OxiBLAS.sparse_ldlt — Function

Sparse symmetric/Hermitian LDL with Bunch–Kaufman 1x1/2x2 pivots, by supernodal multifrontal elimination (src/sparse/supernodal_ldlt.jl). Only uplo is read. Factor identity: A[p,p]=LD(hermitian ? L' : transpose(L)); p is the elimination order (the ordering composed with a postorder and the pivots). pivot=:none is also supported. Exact zero pivots are errors, not perturbations.

source
OxiBLAS.sparse_lu — Function

Sparse LU with threshold partial row pivoting, A[p,q] = L·U.

ordering (exact factor):

  • :auto (default): as multifrontal_lu (UMFPACK's symmetric strategy for a mostly symmetric pattern, singletons and AMD(AᵀA) otherwise);
  • :natural: q = 1:n, left-looking Gilbert–Peierls;
  • :colamd, :amd_ata or a permutation vector: Gilbert–Peierls in that column order.

droptol>0 gives threshold incomplete LU in the natural order, with maxfill bounding the retained lower/upper entries per row, by dictionary rows. No dense expansion.

source
OxiBLAS.sparse_lu_blocked — Function

Sparse blocked right-looking LU. Sparse pivot panels are factored in column dictionaries; only the active L21/U12 update front is packed densely for native TRSM/GEMM. Global A is never expanded to an n×n dense matrix.

source
OxiBLAS.sparse_lu_static — Function

Fixed-order sparse LU with phase-preserving diagonal perturbations. A[p,q]+Diagonal(perturbations)=L*U, with p=q from a symmetric prescribed ordering. A perturbed factor solves the modified system, not exactly A. relative=true scales epsilon by the largest input magnitude.

source
OxiBLAS.sparse_matmul — Function

Gustavson CSR×CSR multiplication with a sparse row accumulator and sorted output rows. No dense matrix expansion or external sparse backend.

source

Sparse × sparse for SparseArrays operands, returned as a SparseMatrixCSC. (AB)ᵀ = BᵀAᵀ, and the CSR forms of Aᵀ and Bᵀ share A's and B's storage, so the Gustavson CSR product of the transposes is the CSC of AB: no input or output transposition.

source
OxiBLAS.sparse_mul! — Function

Native CSR SpMV including transpose/adjoint and overlapping x/y snapshots.

source
OxiBLAS.sparse_qr — Function

Sparse Householder QR, A[:,p] = Q·[R; 0].

pivot=true (default): rank-revealing column pivoting by recomputed norms, column by column, with fill in column dictionaries. pivot=false: multifrontal QR (src/sparse/sparseqrmultifrontal.jl) in the column ordering: :natural (p = 1:n), :amd (AMD of AᵀA), :colamd (COLAMD, SPQR's default kind of order) or a permutation vector. The input is never expanded densely.

source
OxiBLAS.sparse_triangular_solve — Function

Native sparse triangular substitution, with transpose/adjoint and unit options. The compressed storage of the operand is used as it is (CSR rows or CSC columns, a SparseMatrixCSC shared without copy); other formats are converted to CSR once. A zero pivot throws SingularException before the result is returned; the right-hand side is never modified.

source
OxiBLAS.symbolic_cholesky — Function

Symbolic Cholesky pattern and elimination forest in the chosen ordering. By default the full pattern is symmetrized; uplo=:L/:U selects one triangle for the upstream symbolic selected-triangle contract. Elimination tree, children, postorder and the row structure of every factor column are computed in O(nnz(L)) (sparse_amd.jl).

source
OxiBLAS.tfqmr — Function

Transpose-free quasi-minimal residual with optional fixed right preconditioning. maxiter counts half-steps; the stopping residual is exact.

source
