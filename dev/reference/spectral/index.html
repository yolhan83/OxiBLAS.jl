Spectral and iterative algorithms

Sources: src/spectral/.

OxiBLAS.BlockKrylovFactor — Type
BlockKrylovFactor{T}

Block Krylov projection, with variable-width blocks after rank deflation. Approximately Abasis = basisprojected + residualbasis*residualcoupling. images stores A*basis; the large operator is never converted to a dense matrix. For a Hermitian operator, the projection is block tridiagonal up to rounding before a thick restart. Full two-pass reorthogonalization is always used.

source
OxiBLAS.ChebyshevFilter — Type
ChebyshevFilter{T,R}

Owned Chebyshev window filter of a Hermitian matrix, with Jackson damping by default. The sparse matrix and its scaled copy are retained. Spectral bounds provided by the caller assert an enclosure; they are not independently certified.

OxiBLAS.FilterWorkspace — Type
FilterWorkspace(P::ChebyshevFilter; columns=1)

Reusable four-buffer Chebyshev recurrence workspace. Sharing serializes calls; metadata and native GEMM/SpMM packing may still allocate.

OxiBLAS.IncrementalSVDFactor — Type
IncrementalSVDFactor{T,R}

Mutable, rank-capped native SVD state for appending rows or columns. Updates factor the stored approximation augmented with the new block; discarded directions from earlier updates cannot be recovered. Use svdsnapshot for a coherent independent copy while other tasks may update this state. lasttruncationnorm and lastprojection_residual are local diagnostics, not a certified cumulative error bound for the original data stream.

SparseSVDWorkspace(A, rank; kwargs...)

Buffers of sparse_svd_lanczos for an m×n matrix and the given rank: pass it as workspace= to repeated calls to avoid reallocating the Krylov bases. Not shareable between concurrent calls.

Reproducible stochastic estimates with a private random stream per call. probe_type is :rademacher, :gaussian or :spherical (covariance I). confidence is metadata, not a certified confidence interval.

OxiBLAS.apply_filter! — Function
apply_filter!(Y, P::ChebyshevFilter, X; α=1, β=0, workspace=nothing, threaded=true) -> Y

Apply the window polynomial to vectors or column blocks. The result is complete before aliased output is changed. alpha=0 avoids reading input values; beta=0 avoids reading previous output values. Plan/workspace storage aliases are rejected. Nonfinite input/recurrence values are rejected.

OxiBLAS.block_arnoldi — Function
block_arnoldi(A; restart=false, kwargs...)

General block Arnoldi Ritz pairs, with true operator residuals. No restart is implied; rank loss shrinks blocks rather than launching scalar solvers. A converged residual does not certify globally extremal selection. Convergence requires norm(Av-lambdav)<=max(atol,rtol*abs(lambda)).

Build a rank-deflating block Arnoldi projection; maxblocks counts blocks, subspace bounds stored basis columns. Initial columns may be dependent. The default factor reserves at most ten blocks, never n columns unconditionally.

OxiBLAS.count_eigenvalues_in_interval — Function
count_eigenvalues_in_interval(A, low, high; method=:auto, boundary_tol=0, kwargs...)

Count with provenance. Returns a NamedTuple, not an unqualified integer. Diagonal counts with boundary_tol=0 and exact endpoint conversion are exact comparisons. Tridiagonal counts use scaled Sturm recurrences in working precision (not certified intervals). General operators report only the verified pairs of a bounded projection.

OxiBLAS.eigenvalues_in_interval — Function
eigenvalues_in_interval(A, low, high; method=:auto, vectors=true, kwargs...)

Find verified Hermitian eigenpairs in the closed interval [low,high]. :auto handles diagonal/tridiagonal structure directly, otherwise builds one bounded block Krylov projection. General partial projections never assert a complete interval count. boundary_tol explicitly widens numerical selection. Current tridiagonal vector extraction computes the full native MRRR spectrum; even vectors=false still forms vectors internally to verify true residuals.

hermitian_spectral_bounds(A; check_hermitian=true) -> (low, high)

OxiBLAS.incremental_svd — Function
incremental_svd(A; rank=..., maxrank=rank, method=:auto, kwargs...) -> IncrementalSVDFactor

Initialize a native incremental SVD. maxrank defaults to the requested rank, so increasing the retained rank later requires a larger explicit cap here. Dense input defaults to :jacobi and also accepts :randomized; sparse input defaults to :randomized (at most rank 16 unless requested) and accepts :lanczos. Only the factor bases are retained, not a copy of the original matrix. Zero requested rank creates a zero approximation.

OxiBLAS.iram — Function
iram(A; nev=1, subspace=..., maxrestarts=30, which=:largest_magnitude, kwargs...)

Implicitly restarted Arnoldi. Unwanted Ritz shifts are chased through the small Hessenberg matrix; the transformed Arnoldi basis and residual are retained. No dense expansion of A and no external eigensolver are used.

OxiBLAS.lobpcg — Function
lobpcg(A; nev=1, B=nothing, maxiter=100, which=:smallest, kwargs...)

Locally optimal block preconditioned conjugate-gradient eigenpairs. Supports a Hermitian positive-definite metric B for AX=BX*Diagonal(values). The Rayleigh–Ritz subspace is span(X, preconditioned residual, old direction).

OxiBLAS.polynomial_filtered_eigenvalues — Function
polynomial_filtered_eigenvalues(A, low, high, nev=...; degree=20, kwargs...)

Filtered block Lanczos with original-operator Rayleigh–Ritz extraction. Retains multiplicities by vector subspaces, never by deduplicating equal values. Requested-pair convergence does not imply completeness of the interval. Constant filters fall back to ordinary block Lanczos. Restarts retain original Ritz vectors and residual enrichment; no partial reorthogonalization or hard locking.

OxiBLAS.shift_invert — Function
shift_invert(A; sigma=0, B=nothing, kwargs...) -> NamedTuple

Eigenvalues of A (or of the pencil (A, B)) nearest to sigma: implicitly restarted Arnoldi (iram) on (A - σB)⁻¹, applied through one sparse LU. Keywords go to iram (nev, subspace, maxrestarts…). Returns the eigenvalues of A, the vectors and their residuals.

OxiBLAS.sparse_svd_lanczos — Function
sparse_svd_lanczos(A, rank; algorithm=:golub_kahan, subspace=..., kwargs...)

Sparse singular triplets with bounded two-sided Golub-Kahan bases. workspace reuses basis, projection, block scratch, Ritz and packing storage; results own their arrays. algorithm=:dilation explicitly retains the prior Hermitian-dilation solver. No automatic normal-matrix/full-spectrum fallback. Default results do not retain the Krylov basis; return_basis=true copies it.

OxiBLAS.thick_restart_arnoldi — Function
thick_restart_arnoldi(A; nev=1, subspace=..., keep=..., maxrestarts=30, kwargs...)

Thick-restarted block Arnoldi / Krylov-Schur for general dense or sparse A. Retains whole real Schur blocks and cached operator images. locking=true soft-locks wanted converged Ritz pairs by retaining their Schur subspace; it never projects with nonorthogonal individual eigenvectors. :selective uses norm-loss/orthogonality checks to trigger a second projection; default :full always uses two passes. True operator residuals decide convergence.

source
OxiBLAS.thick_restart_lanczos — Function
thick_restart_lanczos(A; nev=1, subspace=..., keep=..., maxrestarts=30, kwargs...)

Thick-restarted Hermitian block Krylov eigensolver. Retains keep Ritz vectors together with boundary residual directions, then expands the retained subspace with full reorthogonalization. Uses a full small Rayleigh–Ritz projection, not a short-recurrence tridiagonal after restarting. No hard locking, interval filtering or generalized metric is implied.

OxiBLAS.trace_hutchinson — Function
trace_hutchinson(A; config=StochasticConfig())

Hutchinson trace estimate for real/complex square operators. Complex probes use four unit phases; std_error measures E|error|², not separate real/imaginary confidence intervals. A single probe has unknown (Inf) error.

source
OxiBLAS.trace_xtrace — Function
trace_xtrace(A; config=StochasticConfig(), normalization=:auto, kwargs...)

Optimized exchangeable XTrace, dense or native sparse, real or complex. num_probes retains its existing meaning: p independent input probes, requiring p+rank(A*Omega) <= 2p operator products. normalization=:auto respheres spherical probes; :resphere also accepts Gaussian probes, and :none matches the explicit leave-one-out estimator. Rademacher resphering is rejected because it is biased. The empirical exchangeable error estimate is heuristic; std_error remains NaN.

source
OxiBLAS.trace_xtrace_loo — Function
trace_xtrace_loo(A; config=StochasticConfig())

Exchangeable leave-one-out trace control variate (XTrace family). Each probe is independent of the range basis formed from all other probes. This implementation rebuilds those bases; it does not implement the optimized inverse-triangular XTrace formula. Correlated samples: stderror is NaN. numprobes counts input probes, not the more numerous operator applications.
