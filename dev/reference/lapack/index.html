Dense factorizations and LAPACK

Sources: src/lapack/.

OxiBLAS.BidiagonalFactor — Type

Compact two-sided Householder reduction. A=UBV'; B is upper bidiagonal for tall inputs and lower bidiagonal for wide inputs. Reflector storage is O(m*n). U and V are materialized only when the corresponding property is requested.

source
OxiBLAS.apply_hessenberg_q! — Function
apply_hessenberg_q!(B,F;side=:L,trans=:N,algorithm=:auto,blocksize=32)

Apply Q, Qᵀ or Qᴴ from compact F, on either side, without materializing Q. Vectors support left application. Algorithm :blocked uses compact WY and this package's GEMM; :unblocked applies individual reflectors. Overlap with F is snapshotted. F and B must have identical element types.

source
OxiBLAS.apply_q! — Function

Apply a stored Householder Q on the left/right, with N/T/C semantics. Aliased factor storage is snapshotted before changing the output.

source
OxiBLAS.balance_matrix — Function

Permutation isolation and radix-two Osborne balancing. B=Diagonal(1/scales)A[p,p]Diagonal(scales). Input is not changed.

source
OxiBLAS.cholesky_factor — Function

Blocked LLᴴ Cholesky using the lower triangle; GEMM updates native panels.

source
OxiBLAS.cholesky_inverse — Function

Inverse of a Hermitian positive definite matrix from its Cholesky factor (LAPACK potri): inv(A)=inv(L)'*inv(L), returned as a full Hermitian matrix.

source
OxiBLAS.complete_orthogonal — Function

Rank-revealing complete orthogonal decomposition: A[:,p]=Q[:,1:r]triangularZ[1:r,:]. The middle factor is lower triangular. Uses pivoted QR followed by LQ, and supports minimum-norm least squares.

source
OxiBLAS.eigen_general — Function

General eigenvectors via the real Francis / complex Wilkinson Schur path and block TREVC back/forward substitution. Real 2x2 blocks are preserved during factorization; the returned eigenvectors have one complex column per eigenvalue.

source
OxiBLAS.eigen_generalized — Function

Hermitian-definite generalized eigenproblem AV=BV*Diagonal(values). B must be positive definite. V'BV=I. Uses native Cholesky, TRSM and EVD.

source
OxiBLAS.eigen_hermitian — Function
eigen_hermitian(A;uplo=:U,vectors=true,maxiter=100*max(1,size(A,1)))

Real symmetric/complex Hermitian eigenpairs, ascending eigenvalues. Uses native rank-2 Householder tridiagonalization, diagonal phase correction and implicit QR. Only uplo and the real diagonal are read. vectors=false skips Q construction. Convergence failure throws ConvergenceError; no external BLAS/LAPACK backend.

source
OxiBLAS.eigen_tridiagonal — Function

Eigenpairs of a real symmetric tridiagonal, sorted ascending; implicit QR.

source
OxiBLAS.eigen_tridiagonal_dc — Function

Cuppen divide-and-conquer eigenpairs of a real symmetric tridiagonal. Recursive blocks use independent storage; merges solve the secular rank-one problem, with deflation of repeated poles. vectors=false discards the vectors.

source
OxiBLAS.eigen_tridiagonal_mrrr — Function

MRRR eigenpairs with splitting, robust shifted LDL representations, differential qd and twisted vectors. A failed representation falls back to the native implicit-QR block solver. Selected index/range output is supported.

source
OxiBLAS.expert_solve — Function

Equilibrated LU expert solve with componentwise backward error and iterative refinement. Returns diagnostics and never silently asserts convergence.

source
OxiBLAS.frechet_matrix — Function

Fréchet derivative L_f(A,E) from the upper block of f([A E;0 A]).

source
OxiBLAS.generalized_sylvester — Function

Solve AR-LB=C, DR-LE=F for two (quasi-)triangular pencils. Block substitution with complete pivoting of each 1x1/2x2 coupled system. The result satisfies the scaled right-hand sides: scaleC and scaleF.

source
OxiBLAS.hessenberg_factor — Function
hessenberg_factor(A)

Compact real/complex Householder reduction A=QHQ'. Neither A nor its views are modified. F.H materializes upper Hessenberg H; F.Q materializes Q. Reflector tails and real tau are retained for implicit application. Input is normalized before reduction to protect finite very large/small matrices. The stored matrix is normalized; F.scale restores the upper Hessenberg entries, not the tails.

source
OxiBLAS.inverse_norm_estimate — Function

Hager–Higham estimate of ||A^-1||_1 using native normal/adjoint solves. This is an estimate, not a certified upper bound.

source
OxiBLAS.ldlt_factor — Function

Symmetric/Hermitian indefinite LDL factorization with Bunch–Kaufman 1×1/2×2 diagonal pivot selection. Only the selected input triangle is read. Set pivot=:none for unpivoted LDL. A[p,p]=LD(hermitian ? L' : transpose(L)).

source
OxiBLAS.least_squares — Function

Rank-revealing QR basic least-squares solution (free pivoted variables zero). For a rank-deficient problem this is a basic solution, not the minimum norm solution.

source
OxiBLAS.lq_factor — Function

Householder LQ: A=L*Q, using native QR of A'.

source
OxiBLAS.lu_factor — Function

Partial-pivoted blocked LU. Trailing updates use this package's GEMM.

source
OxiBLAS.matrix_exp — Function

Matrix exponential by degree-13 Padé scaling and squaring (Higham). All products and the rational solve use the native Julia kernels.

source

Generic matrix exponential using a scaled Taylor series in T. The order is chosen by convergence in the scalar provider's active precision, not a fixed Float64 Padé truncation. Requires +,-,*,/,abs,eps,log2,ceil,ldexp and comparison. Hardware types retain their more specific Padé implementation.

source
OxiBLAS.matrix_log — Function

Principal matrix logarithm by complex Schur, inverse scaling/squaring and an atanh series. Singular input is rejected. A finite iteration limit is enforced.

source
OxiBLAS.matrix_sign — Function

Matrix sign via complex Schur. Eigenvalues on the imaginary axis are excluded.

source
OxiBLAS.matrix_sqrt — Function

Principal matrix square root through complex Schur and triangular recurrence. The result is complex even for real input; negative eigenvalues are supported.

source
OxiBLAS.mixed_solve — Function

Native mixed refinement with Float32 low factors and Float64 residuals. See mixed_solve's extended implementation for diagnostics and family selection.

source

Mixed LU/Cholesky/LDL/QR with an explicitly selected low type and generic residuals and updates. Generic inputs preserve their type by default. Reports convergence, metric, low_type and fallback provenance. QR reports a normalized normal residual, not an original-system error bound.

source
OxiBLAS.ql_factor — Function

Householder QL: A=Q*L, lower trapezoid anchored at the lower right.

source
OxiBLAS.qr_factor — Function

Compact Householder QR for real/complex rectangular matrices (unpivoted).

source
OxiBLAS.qr_pivoted — Function

Column-pivoted Householder QR; A[:,p]=Q*R. Column norms are downdated after each reflector and recomputed when cancellation makes the downdate unreliable, with LAPACK's geqp3/laqp2 criterion.

source
OxiBLAS.qr_q — Function

Materialize selected leading columns of Q without allocating the full Q.

source
OxiBLAS.qz_condition — Function

Pencil diagnostics: homogeneous eigenvalue reciprocal condition numbers, and (when split is given) left/right deflating-subspace projection conditions plus a coupled Sylvester inverse-1-norm separation estimate. No dense n^4 Kronecker operator is formed. Estimates are not certified error bounds.

source
OxiBLAS.qz_factor — Function

Generalized Schur A=QSZ', B=QTZ'. Real input returns real S with isolated 1x1/2x2 blocks and triangular T; complex input returns triangular S/T. form=:complex explicitly requests the complex path for real input. Homogeneous alpha/beta pairs include infinite and indeterminate eigenvalues.

source
OxiBLAS.qz_reorder — Function

Reorder whole real 1x1/2x2 or complex 1x1 generalized Schur blocks. The selector receives a generalized eigenvalue (possibly Inf/NaN). Selecting either member of a real pair selects its entire block. Input is not modified.

source
OxiBLAS.refine_solve — Function

Iterative refinement in the generic work type; Float32 residuals widen to Float64. Returns componentwise backward error, true residual norm and estimated forward error/reciprocal condition. These condition estimates are explicitly non-certified.

source
OxiBLAS.rq_factor — Function

Householder RQ: A=R*Q, upper trapezoid anchored at the upper right.

source
OxiBLAS.schur_factor — Function
schur_factor(A;maxiter=100*max(1,size(A,1)))

Native Schur decomposition A=ZTZ'. Real inputs use Francis double-shift bulge chasing and return real quasi-triangular T (1x1/2x2 blocks); complex inputs use implicit single-shift QR and triangular T. Eigenvalues are complex. Finite input is scaled before reduction. Failure to converge throws ConvergenceError, including the remaining active block and iteration count. No balancing, reordering or eigenvector back substitution is performed.

source
OxiBLAS.schur_multishift — Function

Native real/complex multishift Schur: aggressive early deflation, concurrent small-bulge train, and accumulated blocked far updates. Real input preserves real 1x1/2x2 blocks. workspace reuses panel and update buffers; a shared context is serialized, with reentrant use rejected. No external eigensolver is called.

source
OxiBLAS.schur_reorder — Function

Stably move selected eigenvalues to the leading complex Schur block. Adjacent unitary swaps preserve A=ZTZ'. Repeated inseparable eigenvalues are rejected if a requested swap cannot distinguish their invariant subspaces.

source
OxiBLAS.svd_bidiagonal — Function

SVD through two-sided Householder reduction and bidiagonal Golub–Kahan QR. algorithm=:divide_conquer instead solves the symmetric bidiagonal dilation by Cuppen recursion and secular merges; no A'A is formed. Real/complex, tall/wide, values-only and full null-space options are supported.

source
OxiBLAS.svd_factor — Function
svd_factor(A;vectors=true,maxsweeps=100,rtol=8eps(real(eltype(A)))*sqrt(min(size(A)...)))

Economy SVD A=UDiagonal(S)Vt, sorted descending, for real/complex rectangular matrices, including empty and rank-deficient inputs. Native one-sided cyclic Jacobi; never forms the full Gram matrix. Wide matrices are handled through their adjoints. Column norms and normalized correlations protect graded inputs. Correlated columns at the working type's underflow floor are deflated to zero; orthogonal tiny columns are retained. vectors=false returns U=Vt=nothing. Nonconvergence throws ConvergenceError. full=true completes the null spaces. algorithm=:parallel_jacobi selects disjoint column rounds; :golub_kahan and :divide_conquer use the bidiagonal entry point.

source
OxiBLAS.svd_randomized — Function

Randomized range-finder SVD with explicit local seed and reorthogonalized power steps. Intended for low target rank; residual quality is caller-controlled.

source
OxiBLAS.svd_selected — Function

Genuine selected dense SVD, with 1-based descending indices, or the half-open value interval (low,high]. Only the requested distinct ranks are bisected and only their vectors are computed/backtransformed. Index order and duplicates are preserved. With neither selector, all min(m,n) values are requested.

representation=:dilation uses the symmetric bidiagonal linearization, avoiding B'B's squared conditioning. :gram ports Rust's tridiagonal B'B representation explicitly. No external solver or full-spectrum safety fallback is used. diagnostics=Ref{Any}() receives work counts, without changing SVDFactor.

source
OxiBLAS.svd_truncated — Function

Leading-rank SVD. The default uses genuine selected bisection/inverse iteration. Explicit :golubkahan/:divideconquer retain the full-spectrum paths.

source
OxiBLAS.trevc_right — Function

Native block TREVC. Real input stores a conjugate pair as real/imaginary columns, as in OxiBLAS Rust; complex input returns complex eigenvectors. packed=false returns one complex vector per eigenvalue for real input too.

source
OxiBLAS.tridiagonal_factor — Function
tridiagonal_factor(A;uplo=:U)

Reduce a symmetric/Hermitian matrix to a real symmetric tridiagonal: A=QTQ'. Only the chosen triangle and real diagonal are read. The compact Householder representation retains the diagonal phase correction needed for complex eigenvectors. F.diagonal/F.offdiagonal are in input units; the fields diag/offdiag are normalized by F.reflectors.scale.

source
OxiBLAS.trsna_s — Function

Reciprocal eigenvalue condition numbers |y'x|/(norm(y)norm(x)). Ports Rust TRSNA-S, including one common value for a real conjugate pair.

source
OxiBLAS.trsna_sep — Function

Rust TRSNA-SEP's spectral-distance estimate (not a singular-value sep). Repeated eigenvalues return zero; an isolated block has no complement and returns Inf. Use schur_condition for the coupled invariant-subspace estimate.
