OxiBLAS.PackedMatrix — Type
PackedMatrix(data, n; uplo=:U, kind=:symmetric, unit=false)

BLAS packed storage of a symmetric, Hermitian or triangular matrix of order n: the uplo triangle stored column by column in data (length n(n+1)/2). kind is :symmetric, :hermitian or :triangular (unit: implicit unit diagonal). Built from a dense matrix with pack_matrix; used by spmv!, tpsv!, packed_cholesky and the high-level API (OxiBLAS.cholesky, \).

P = pack_matrix(H; uplo=:U, kind=:symmetric)
y = zeros(n); spmv!(y, P, x)          # y = H*x

OxiBLAS.aasen_factor — Function

Partially pivoted Aasen tridiagonal congruence A[p,p]=LTL' (or LTL^T). The first column of the unit lower L stays e1. Only uplo is read.

source
OxiBLAS.band_lu — Function

Partial-pivoted band LU in (2kl+ku+1)×n compact storage. Local pivot operations and multipliers are retained in elimination order, as in GBTRF. No full matrix expansion is made.

source
OxiBLAS.band_matrix — Function
band_matrix(A; kl=0, ku=0, kind=:general, uplo=:U, unit=false) -> BandedMatrix

Copies the band of A into a BandedMatrix: kl subdiagonals and ku superdiagonals for kind=:general; for :symmetric, :hermitian and :triangular the uplo triangle with max(kl, ku) off-diagonals. Only the band is read.
