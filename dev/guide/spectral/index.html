Spectral and iterative algorithms

The dense spectral decompositions (Schur, Hermitian, SVD, QZ) are described in Dense factorizations. This page covers the iterative and partial methods, usable on dense or sparse matrices.

using OxiBLAS, SparseArrays, LinearAlgebra
n = 200
L = spdiagm(-1 => -ones(n-1), 0 => 2ones(n), 1 => -ones(n-1))   # 1-D Laplacian
r = lobpcg(CSRMatrix(L); nev=3, which=:smallest)
(r.converged, r.values)
(false, [0.0002445564475711721, 0.0009785132188212839, 0.0023231507256376836])

Stochastic estimators

trace_hutchinson, trace_hutch_plus_plus, trace_xtrace and trace_xtrace_loo estimate the trace. stochastic_diagonal, stochastic_frobenius and stochastic_logdet estimate the diagonal, the Frobenius norm and the log-determinant. All are configured by StochasticConfig(; num_probes, seed, ...), with an explicit seed and no global state.
