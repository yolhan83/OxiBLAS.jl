How do I…?

Task-oriented recipes. Each example runs when the documentation is built. Every function named here has its full description in the API reference (search box, top left).

using OxiBLAS, LinearAlgebra, SparseArrays

The sparse examples use a 2-D Laplacian, symmetric positive definite:

k = 30
T1 = spdiagm(-1 => -ones(k-1), 0 => 2ones(k), 1 => -ones(k-1))
L = kron(sparse(1.0I, k, k), T1) + kron(T1, sparse(1.0I, k, k))   # 900×900
A = CSRMatrix(L)                                                 # OxiBLAS format
b = ones(size(A, 1))

Solve a linear system

Dense, direct

M = randn(200, 200) + 200I; c = randn(200)
x = OxiBLAS.ldiv(M, c)              # factorize + solve (LU here)
F = OxiBLAS.lu(M)                   # keep the factorization to reuse it
x2 = F \ c                          # or OxiBLAS.ldiv(F, c)
y = similar(c); OxiBLAS.ldiv!(y, F, c)   # in place, no allocation of the result
norm(M * y - c) / norm(c)
8.347425279455068e-16

The engine-level form is lu_factor + solve; use cholesky_factor for Hermitian positive definite matrices and ldlt_factor / bunchkaufman_factor for symmetric indefinite ones. OxiBLAS.factorize(M) chooses from the structure.

Sparse, direct

x = A \ b                           # multifrontal LU or Cholesky, chosen from the structure
F = OxiBLAS.factorize(A)            # reuse: Cholesky here (symmetric positive definite)
x2 = OxiBLAS.ldiv(F, b)
y = similar(b); OxiBLAS.ldiv!(y, F, b)   # in-place solve (0 allocations for Cholesky)
norm(L * y - b) / norm(b)
2.5285368316057948e-14

The engines are multifrontal_lu, multifrontal_cholesky, sparse_ldlt (indefinite) and sparse_qr (least squares). For in-place solves (OxiBLAS.ldiv!(Y, F, B) or LinearAlgebra.ldiv!(F, B)), Cholesky reuses its internal supernodal buffer under its lock (0 allocations) and LU / LDLt / BunchKaufman / QRSparse solve in place with a single column-sized working vector.

Iteratively (Krylov methods)

Every solver returns a named tuple (; x, converged, iterations, residual, reason); residual is the recomputed true residual norm. Common keywords: x0 (initial guess), rtol, atol, maxiter, preconditioner.

r = cg(A, b; rtol=1e-10)                              # Hermitian positive definite
(r.converged, r.iterations, r.residual)
(true, 62, 1.1354493393214559e-9)
r = pcg(A, b; preconditioner=ic0(A), rtol=1e-10)      # incomplete Cholesky
(r.converged, r.iterations)
(true, 32)
N = CSRMatrix(L + 0.3 * spdiagm(1 => ones(size(L,1)-1)))  # nonsymmetric
r = gmres(N, b; preconditioner=ilu0(N), restart=30, rtol=1e-10)
(r.converged, r.iterations)
(true, 18)
SolverMatrix
cg, pcgHermitian positive definite
minresHermitian, possibly indefinite
gmres, fgmres (flexible: variable preconditioner)general
bicgstab, tfqmr, qmr, idrsgeneral, short recurrences (less memory than GMRES)
block_cg, block_gmresseveral right-hand sides at once

Preconditioners: ilu0, ilut, ic0, ict, amg (algebraic multigrid), spai, ainv, relaxation_preconditioner (Gauss–Seidel, SOR, SSOR), polynomial_preconditioner, additive_schwarz, a vector (Jacobi: the diagonal), or a sparse direct factor.

r = pcg(A, b; preconditioner=amg(A), rtol=1e-10)      # multigrid: few iterations
(r.converged, r.iterations)
(true, 9)
B = randn(size(A, 1), 4)                             # four right-hand sides
r = block_cg(A, B; rtol=1e-8)
(r.converged, r.iterations, maximum(r.residuals))
(true, 66, 2.3784333386231735e-7)

Least squares

Tall = randn(300, 40); d = randn(300)
F_qr = OxiBLAS.qr(Tall)
x = F_qr \ d                                 # or OxiBLAS.ldiv(Tall, d)
y = zeros(40); ws = zeros(300)               # 300-row workspace reused across solves
OxiBLAS.ldiv!(y, F_qr, d; workspace=ws)      # in-place least squares (0 allocations)
norm(Tall' * (Tall * y - d))                 # normal equations satisfied
4.510550899063205e-14

Rank-deficient problems: qr_pivoted or complete_orthogonal (minimum-norm solution). Underdetermined (wide) minimum-norm problems: OxiBLAS.lq(Wide) or OxiBLAS.svd(Wide), where OxiBLAS.ldiv!(y, F, b) solves directly into y without needing a workspace. Sparse: OxiBLAS.qr(A_sparse) (or sparse_qr then solve).

Check a solution

x = OxiBLAS.ldiv(M, c)
backward_error(M, x, c).error                # componentwise backward error
8.778812191691835e-16

refine_solve adds iterative refinement with condition estimates; expert_solve adds equilibration.

Compute an SVD

Full SVD

X = randn(120, 80)
S = OxiBLAS.svd(X)                     # S.U, S.S, S.Vt (and S.V)
norm(S.U * Diagonal(S.S) * S.Vt - X) / norm(X)
4.0926953866879585e-15
F = svd_factor(X; algorithm=:golub_kahan)   # engine: :jacobi (default, most accurate),
F.S[1:3]                                    # :golub_kahan, :divide_conquer (fastest)
3-element Vector{Float64}:
 19.869201391417068
 19.018593155917024
 18.336707461943966

Singular values only

OxiBLAS.svdvals(X)[1:3]                # or singular_values(X)
3-element Vector{Float64}:
 19.86920139141712

A few singular triplets

T5 = svd_truncated(X, 5)               # the 5 largest, without the full SVD
R5 = svd_randomized(X, 5)              # randomized range finder: fastest for low ranks
I3 = svd_selected(X; indices=1:3)      # chosen indices (or interval=(lo, hi))
(T5.S, R5.S[1:2], I3.S)
([19.86920139141713, 19.018593155917067, 18.336707461944034, 18.08056530747067, 17.672968875013883], [19.752147856697572, 18.622191897334424], [19.86920139141713, 19.018593155917067, 18.336707461944034])

Sparse matrix

s = sparse_svd_lanczos(A, 4)           # Golub–Kahan–Lanczos with thick restart
(s.converged, s.S)
(true, [7.979477293567533, 7.948798529288794, 7.948798529288774, 7.918119765009977])

sparse_svd is the randomized variant. For data that arrives by rows or columns, incremental_svd is updated by svd_add_rows! / svd_add_columns!.

Compute eigenvalues

Dense

H = Symmetric(randn(100, 100))
E = OxiBLAS.eigen(H)                   # Hermitian: real values, orthonormal vectors
G = OxiBLAS.eigen(randn(100, 100))     # general: complex values
(E.values[1:2], G.values[1:2])
([-18.773115370342, -18.44874943721538], ComplexF64[-9.402112585399035 + 0.0im, -8.36755307579235 - 5.154759214660469im])

Engines: eigen_hermitian (with algorithm), eigen_hermitian_dc (divide and conquer), eigen_hermitian_mrrr (subset by indices or interval), eigen_general, schur_factor. Generalized problems: OxiBLAS.eigen(A, B), eigen_generalized (Hermitian definite), eigen_pencil (QZ).

A few eigenvalues of a large (sparse) matrix

r = lobpcg(A; nev=3, which=:smallest, preconditioner=ic0(A))   # Hermitian; preconditioned
(r.converged, r.iterations, r.values)
(true, 43, [0.02052270643241943, 0.05120147071122069, 0.05120147071122101])
r = lanczos(A; nev=3, which=:largest, maxiter=300)   # Hermitian Lanczos; maxiter = subspace size
(r.converged, r.values)
(true, [7.979477293567583, 7.948798529288824, 7.948798529288749])
r = shift_invert(A; sigma=1.0, nev=3)           # eigenvalues closest to sigma
real.(r.values)
3-element Vector{Float64}:
 0.9830120968410861
 0.9805392794340743
 1.0270948026155102

Check r.converged: the iteration budgets (maxiter, maxrestarts) are finite, and an unconverged result is returned, not raised. Non-Hermitian: arnoldi, iram (implicit restarts), thick_restart_arnoldi. All eigenvalues in an interval: eigenvalues_in_interval (Chebyshev filtering).

Other matrix computations

P = Symmetric(randn(50, 50)) + 60I
(OxiBLAS.exp(P) ≈ exp(Matrix(P)), OxiBLAS.sqrt(P)^2 ≈ P, matrix_power(P, 3) ≈ Matrix(P)^3)
(true, true, true)
D = randn(30, 10) * randn(10, 20)              # rank 10
(numerical_rank(D), size(null_space(D)), condition_number(randn(5, 5)) > 1)
(10, (20, 10), true)

Also: OxiBLAS.det, logabsdet, inv, pinv (pseudoinverse), OxiBLAS.log, sin, cos, sylvester, lyap, frechet_exp, kron_product, kronecker_action.

Compute determinants on singular or indefinite matrices

# Singular sparse matrix with zero diagonal pivot
S_sing = spdiagm(0 => [1.0, 0.0, 2.0, 3.0])
(OxiBLAS.det(S_sing), OxiBLAS.logabsdet(S_sing))   # returns (0.0, (-Inf, 0.0))
(0.0, (-Inf, 0.0))

Factorizations also allow preserving the singular state via check=false:

F_sing = OxiBLAS.lu(S_sing; check=false)
(LinearAlgebra.issuccess(F_sing), LinearAlgebra.logabsdet(F_sing))
(false, (-Inf, 0.0))

While det(F_sing) computes 0.0, trying to solve F_sing \ b safely throws a SingularException.

Multiply matrices

P1 = randn(300, 200); P2 = randn(200, 100); C = zeros(300, 100)
w = GemmWorkspace(Float64, 300, 100, 200)      # reused buffers: no allocation per call
gemm!(C, P1, P2, 1.0, 0.0; workspace=w)        # C ← 1·P1·P2 + 0·C
OxiBLAS.mul!(C, P1, P2)                        # high-level: also structured and sparse operands
C ≈ P1 * P2
true
y = zeros(size(A, 1)); OxiBLAS.mul!(y, A, b)   # sparse × dense (A*b)
z = OxiBLAS.mul(A, A)                          # sparse × sparse: sparse result
(y ≈ L * b, nnz(SparseMatrixCSC(z)))
(true, 11104)

Work with sparse matrices

As = sparse_permute(A, sortperm(rand(size(A, 1))))   # the Laplacian, randomly renumbered
p = reverse_cuthill_mckee(As)                        # bandwidth-reducing ordering
(bandwidth_profile(As).bandwidth, bandwidth_profile(sparse_permute(As, p)).bandwidth)
(1783, 61)
path = tempname() * ".mtx"
write_matrix_market(path, A; symmetry=:symmetric)
A2 = read_matrix_market(path)                  # CSRMatrix by default (format=:csc, :coo, :dense)
A2 ≈ A
true

Formats: CSRMatrix, CSCMatrix, COOMatrix, DIAMatrix, ELLMatrix, BSRMatrix, HYBMatrix, SELLMatrix; each converts from a SparseMatrixCSC (CSRMatrix(S)) and back (SparseMatrixCSC(A)). Orderings: amd_ordering, nested_dissection, select_sparse_ordering (compares several).

Work with tensors

X3 = randn(8, 9, 10); Y2 = randn(10, 7)
Z = einsum("abc,cd->abd", X3, Y2)              # Einstein summation
Pl = plan_einsum("abc,cd->abd", X3, Y2)        # plan once, run many times
Z2 = similar(Z); einsum!(Z2, Pl, X3, Y2)
(size(Z), Z ≈ Z2, contract(X3, Y2, (3,), (1,)) ≈ Z)
((8, 9, 7), true, true)
Tk = hosvd(randn(6, 7, 8); ranks=(3, 3, 3))     # Tucker decomposition
size(reconstruct(Tk))
(6, 7, 8)
